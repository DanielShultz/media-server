# Media server

Общие правила рабочей среды читаются из локальной приватной конфигурации, если она доступна; в публичный репозиторий их пути и содержимое не копируются.
Пользователь постоянно разрешил pre-task backup commit/push своих правок и
финальный commit/tag/push после обязательных проверок. Явный запрет в текущей
задаче имеет приоритет. Не включать незавершённую работу другого чата и секреты.
Перед публикацией проверять AGENTS.md, README, примеры, tracked-файлы и outgoing commits на внутренние пути, адреса и приватные ссылки.
Применяй `$server-project-versioning`, затем `$server-git-autosave`.
Версия этого репозитория — `VERSION`; рабочая upstream-ветка сейчас `master`.
Push не разрешает применять Compose, перезапускать сервисы или менять данные.
Полный регламент версионирования хранится отдельно в приватной документации владельца.
